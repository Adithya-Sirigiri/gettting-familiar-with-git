BASIC GIT COMMANDS (CHEAT SHEET)

->Check Git version
git --version

->Initialize repository (one time)
git init

->Check status
git status

->Add files to staging area
git add .
git add <file_name>
git add <folder_name>
git add -A

->Commit changes
git commit -m "commit message"

->Change last commit message
git commit --amend -m "new message"

->Connect to GitHub (one time)
git remote add origin <repo_url>

->View remotes
git remote -v

->Push changes
git push
git push -u origin main

->Pull changes
git pull

->View commit history
git log
git log --oneline

->Unstage a file
git restore --staged <file_name>

->Discard local changes
git restore <file_name>

->Check differences
git diff

->Clone a repository
git clone <repo_url>
