ADVANCED GIT COMMANDS (CHEAT SHEET)
==================================

1. HISTORY & INSPECTION

Compact commit history
git log --oneline --graph --all

Show changes in last commit
git show

Show changes between commits
git diff <commit1> <commit2>

Show who changed each line
git blame <file_name>

2. STAGING (ADVANCED CONTROL)

Stage parts of a file (very important)
git add -p

Unstage a file
git restore --staged <file_name>

Unstage everything
git restore --staged .

3. UNDO & FIX MISTAKES

Change last commit message
git commit --amend -m "new message"

Undo last commit (keep changes)
git reset --soft HEAD~1

Undo last commit (discard changes)
git reset --hard HEAD~1

Discard local changes to a file
git restore <file_name>

Discard all local changes
git restore .

4. BRANCHING (CORE ADVANCED SKILL)

List branches
git branch

Create a new branch
git branch <branch_name>

Switch branch
git checkout <branch_name>
# or modern way
git switch <branch_name>

Create and switch at once
git checkout -b <branch_name>
# or
git switch -c <branch_name>

Delete a branch
git branch -d <branch_name>

5. MERGING & REBASING

Merge a branch
git merge <branch_name>

Rebase current branch
git rebase <branch_name>

Abort a rebase
git rebase --abort

6. REMOTE & GITHUB

Check remotes
git remote -v

Rename branch to main
git branch -M main

Force push (use carefully)
git push --force

Delete remote branch
git push origin --delete <branch_name>

7. STASH (TEMPORARY SAVE)

Save work temporarily
git stash

List stashes
git stash list

Apply last stash
git stash apply

Apply and remove stash
git stash pop

Drop a stash
git stash drop

8. TAGS (RELEASE MARKING)

Create a tag
git tag v1.0

List tags
git tag

Push tags
git push --tags

9. CLEANING (DANGEROUS ZONE)

Preview untracked files to delete
git clean -n

Delete untracked files
git clean -f

Delete untracked files + folders
git clean -fd

10. CONFIGURATION

Set username
git config --global user.name "Your Name"

Set email
git config --global user.email "you@email.com"

Check config
git config --list
